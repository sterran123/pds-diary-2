## 1일차에 확정한 것 (이후 바꾸지 않음)

- **질문 한 문장**: (예시) 오전에 두 시간 블록을 먼저 잡아 두면 그날 집중 시간이 늘어날까?
- **관찰 지표**: (예시) 집중 시간
- **단위**: 분
- **계산 규칙**: 하루 동안 알림 없이 몰두해 일한 시간의 합(분). 돌아보기에서 재는 시간.
- **계획 규칙**: 하루에 새로 시작하는 할 일은 3개까지
- **주 시작 요일**: 월요일
- **집계 규칙** (계약과 동일):
  - 빠진 값 — 기록 없는 날은 '—' 표시, 합계·평균 분모에서 제외
  - 중복 값 — 같은 날짜는 created_at이 가장 늦은 한 건만 사용
  - 튀는 값 — 0~1440분 밖은 이상치로 표시하고 집계 제외(입력 시에도 거부)
  - 반올림 — 평균은 소수 첫째 자리 반올림, 합계는 원본 정수
